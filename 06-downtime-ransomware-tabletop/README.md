# Downtime and Ransomware Tabletop

This module helps a practice document downtime procedures, restore testing, tabletop evidence, incident contact trees, and post-incident improvement tasks.

It is a packet generator concept, not a SOAR platform.

The deeper incident workflow now lives in `08-incident-evidence-timeline/`. Use this module for continuity planning and tabletop prompts; use the incident evidence timeline for the event sequence, evidence-reference handoff, decision gates, and after-action remediation queue.
