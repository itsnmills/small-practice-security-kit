# v0.1.0 Public Proof Release

Target tag: `v0.1.0`

This release makes `small-practice-security-kit` the public proof anchor for the Velari small-practice readiness workflow.

## What It Shows

- A complete synthetic `Family Dental Clinic` demo packet.
- Local-first intake and packet generation.
- Patient-data-outside-the-EHR mapping.
- Vendor, BAA, AI workflow, downtime, incident, and evidence-binder outputs.
- Owner/MSP handoff artifacts and a 30/60/90 roadmap.
- A ChainRisk import path for attack-chain prioritization.
- A PHI-avoidant safety boundary and limitations appendix.

## Verification Gate

Run before publishing:

```bash
python3 scripts/validate_content.py
python3 -m unittest discover -s tests
```

Expected result:

- content validation passes;
- all unit tests pass;
- generated demo artifacts remain synthetic and PHI-avoidant.

## Boundaries

This release is a readiness and evidence organizer. It does not provide legal advice, certify HIPAA compliance, determine breach obligations, perform penetration testing, or replace qualified security/compliance review.
