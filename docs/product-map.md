# Product Map

The open-source ecosystem should feel like one family, not a pile of scripts.

```text
Small Practice Security Kit
├── readiness checklist
├── ePHI data flow map
├── HIPAA evidence binder
├── vendor and BAA review
├── AI workflow review
├── downtime and ransomware tabletop
└── review packet builder
```

The practical user journey is:

```text
start -> intake -> map ePHI -> review vendors -> review AI workflows -> collect evidence -> build review packet -> plan 30/60/90
```

Future integrations should import from existing companion repos instead of duplicating their full functionality.
